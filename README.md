# steph

```bash
# install dependencies
bun install

# run TUI client
bun start

# run web server via arg
bun start web --port 3000

# run web server via env
PORT=3000 bun start web

# run TUI dev client with hot-reload
bun run dev:tui

# run web dev server with hot-reload, port 3000 by default
bun run dev:web

# build tailwind styles.css
bun run build:tailwind
```
